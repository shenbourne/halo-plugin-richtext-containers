# 版本与内容兼容

## 首次市场版本

本次 `1.0.0` 包含选项卡、幻灯片、提示容器及脚注。此前本地实验包的版本标签不再用于发行，旧包及原始验证材料保存在本地归档中，不属于源码发布包。

插件标识 `richtext-containers`、八个 `rc*` 富文本节点及 `data-rc-*=v1` HTML 标记保持不变。本次版本重置不批量改写文章，不修改已有脚注标识，也不要求内容迁移脚本。由旧包保存的合法文档仍应通过这些原有节点读取；缺失标记、手工破坏层级的 HTML 不属于有效格式。

## 已安装实验版

1. 完整备份 Halo，并保留文章或页面的历史版本。优先在站点副本上试装。
2. 关闭正在编辑的内容；不要在插件停用或卸载时保存包含扩展节点的文章。
3. 如 Halo 允许上传替换，直接安装新 `1.0.0`；如果拒绝同版本替换或从更高编号的实验版降级，则先停用并卸载实验包，再安装新包并启用。插件没有单独的数据删除选项，也不删除正文。
4. 刷新控制台，打开原有文章，核对四类节点、嵌套正文、标签默认项和脚注链接。再保存并重开一次，确认内容未丢失。
5. 核对文章及独立页面的前台渲染、手机视口和主题样式。

Windows 上直接覆盖正在加载的同名 JAR 可能产生文件占用错误。此时遵循停用、卸载、再安装的顺序；必要时重启 Halo 后重试，不要修改数据库或强行删除正在使用的文件。不同版本的正式升级使用不同版本文件名。

早期不含脚注的实验包不认识新增的脚注节点，不应再用于编辑当前文档。不要通过修改 Halo 数据库中的插件版本号强行降级。

## 后续正式升级与回滚

以后从上一正式版本升级，先备份，再安装更高版本 JAR。已发布版本及制品不覆盖。数据结构发生不兼容变化时，将单独提供迁移及回滚说明。

回滚优先恢复完整站点备份；只替换旧插件包不能保证识别新版本添加的节点。卸载及停用后的正文保留策略见 README。
